- Interests: sastra, komunikasi, kucing, jalan-jalan

## Cara lihat lokal
Buka saja `index.html` di browser.

## Deploy ke GitHub Pages
1. Push repo ini ke GitHub
2. Settings → Pages → Source: Deploy from a branch → `main` / `master` → root
3. Tunggu beberapa menit, website akan live di `https://username.github.io/nama-repo`
